# pairwise-crowd-orca

密集人群在窄门口互相顶住，ORCA 只按当前速度算半平面，没把未来 2 秒的拥堵传播算进去；动态障碍的半径用包围盒对角线，角色贴着柱子走时被推出去；局部避障和导航网格各算一套目标点，出口在网格外时人群原地打转；时间窗固定 1 秒，快速角色在窗口外才相遇，避障来不及；确定性排序按实体 id，跨平台哈希顺序不同，回放对不上；密度超过阈值后直接降采样，门口外侧的人被删除导致内侧真空；角色被击退时避障速度没清零，恢复后沿旧方向冲出去；多线程分区各自求解，边界上的角色收到两份相反推力；上下坡时速度按水平面算，Running 下坡冲进人群；预测轨迹只考虑静态障碍，没处理其他角色的加速度。gameplay/crowd_avoidance.py 是核心，tests/test_crowd_avoidance.py 15个红。要修的是：半平面加拥堵传播；障碍用真实半径；避障与寻路共用目标；时间窗按相对速度自适应；确定性排序用稳定键；超密度做速度限制不删人；击退清速度；分区边界统一求解；速度按地面切向；预测含他人加速度。

## 运行

```bash
python -m pytest tests -q
```
